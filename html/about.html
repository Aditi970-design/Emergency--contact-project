ABOUT OUR PROJECT

Making emergency information accessible.

Emergency Contact is a student project created to provide quick access to emergency information and basic safety resources.

Our Mission

Our mission is to make essential emergency contact information easy to find and understand. The website brings together emergency numbers, safety tips, and a simple question-answer assistant in one place.

This project demonstrates how HTML, CSS, and JavaScript can be used to create a responsive, multi-page website with interactive features.

Project Disclaimer

This website is an educational project and is not affiliated with government emergency services. Always contact the appropriate official service during an actual emergency.
